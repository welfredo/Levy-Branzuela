# Levy Branzuela Salon — Booking & Service Management Demo

A GitHub Pages-ready front-end prototype for the proposed Levy Branzuela Salon Booking and Service Management System.

## Features
- Salon landing page and service menu
- Appointment request form with date/time selection
- Demo bookings saved to the current browser using `localStorage`
- View and cancel demo booking requests
- Concept section for salon supply inventory (hair products, towels, nail-care supplies)
- Responsive layout for mobile and desktop

## Run it
Open `index.html` in a browser or upload the folder contents to a GitHub repository and enable GitHub Pages.

## Important
This is a **front-end demonstration only**. It does not have a backend, real customer database, login, email notification, real appointment availability, or real inventory transactions. Prices are sample estimates and should be replaced with confirmed salon prices. No real appointment is created.
